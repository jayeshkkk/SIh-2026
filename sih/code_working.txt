================================================================================
                    STEP 2: CALCULATE ROAD RISK SCORE
================================================================================

FUNCTION: calculate_road_risk(road)
INPUT: Single RoadSegment object

DATA SOURCES FOR THIS STEP:
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│  Step 2A: FETCH WEATHER DATA                                   │
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│  For each Road Segment:                                        │
│                                                                 │
│  Step 2A: FETCH WEATHER DATA                                   │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ SELECT weather FROM WeatherData                          │  │
│  │ WHERE district_id = road.district_id                     │  │
│  │ ORDER BY recorded_at DESC                                │  │
│  │ LIMIT 1                                                  │  │
│  │                                                          │  │
│  │ Calculate: rainfall_risk = f(rainfall_mm)                │  │
│  │ • > 100mm → 1.0  (100%)                                 │  │
│  │ • > 50mm  → 0.7  (70%)                                  │  │
│  │ • > 20mm  → 0.4  (40%)                                  │  │
│  │ • ≤ 20mm  → 0.1  (10%)                                  │  │
│  └──────────────────────────────────────────────────────────┘  │
│                        ↓                                        │
│  Step 2B: EVALUATE TERRAIN TYPE                                │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ Lookup: terrain_risk = TERRAIN_MAP[road.terrain_type]    │  │
│  │                                                          │  │
│  │ Mapping:                                                │  │
│  │ • plains       → 0.1  (safest)                          │  │
│  │ • hilly        → 0.5  (medium)                          │  │
│  │ • mountainous  → 0.8  (highest)                         │  │
│  └──────────────────────────────────────────────────────────┘  │
│                        ↓                                        │
│  Step 2C: CHECK ROAD CONDITION                                 │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ Lookup: condition_risk = CONDITION_MAP[road.condition]   │  │
│  │                                                          │  │
│  │ Mapping:                                                │  │
│  │ • good  → 0.1  (well maintained)                        │  │
│  │ • fair  → 0.4  (acceptable)                             │  │
│  │ • poor  → 0.8  (deteriorated)                           │  │
│  └──────────────────────────────────────────────────────────┘  │
│                        ↓                                        │
│  Step 2D: EVALUATE TRAFFIC LEVEL                               │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ Lookup: traffic_risk = TRAFFIC_MAP[road.traffic_level]   │  │
│  │                                                          │  │
│  │ Mapping:                                                │  │
│  │ • none      → 0.0  (empty)                              │  │
│  │ • light     → 0.1  (low congestion)                     │  │
│  │ • normal    → 0.2  (standard)                           │  │
│  │ • moderate  → 0.4  (medium congestion)                  │  │
│  │ • heavy     → 0.6  (congested)                          │  │
│  └──────────────────────────────────────────────────────────┘  │
│                        ↓                                        │
│  Step 2E: CHECK BRIDGE STATUS                                  │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ SELECT bridges FROM Bridge                              │  │
│  │ WHERE district_id = road.district_id                     │  │
│  │                                                          │  │
│  │ Evaluate: bridge_risk                                    │  │
│  │ • If status = "closed"  → risk = 1.0  (impassable)      │  │
│  │ • If status = "partial" → risk = 0.5  (limited)         │  │
│  │ • If condition = "poor" → risk = 0.4  (unsafe)          │  │
│  │ • Else                  → risk = 0.0  (safe)            │  │
│  └──────────────────────────────────────────────────────────┘  │
│                        ↓                                        │
│  Step 2F: COUNT HISTORICAL INCIDENTS                           │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ SELECT COUNT(*) FROM Alert                              │  │
│  │ WHERE (affected_districts CONTAINS from_location OR      │  │
│  │        affected_districts CONTAINS to_location)          │  │
│  │ AND created_at > (NOW - 7 days)                          │  │
│  │                                                          │  │
│  │ Calculate: historical_risk = min(alert_count × 0.15, 1) │  │
│  │ • Each incident: +0.15 risk (capped at 100%)            │  │
│  │ • Example: 4+ incidents → 1.0 risk                      │  │
│  └──────────────────────────────────────────────────────────┘  │
│                        ↓                                        │
│  Step 2G: APPLY WEIGHTED FORMULA                               │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ Risk = (0.25 × rainfall_risk) +                          │  │
│  │        (0.20 × terrain_risk) +                           │  │
│  │        (0.20 × condition_risk) +                         │  │
│  │        (0.10 × traffic_risk) +                           │  │
│  │        (0.15 × bridge_risk) +                            │  │
│  │        (0.10 × historical_risk)                          │  │
│  │                                                          │  │
│  │ Risk Range: [0.0, 1.0]                                  │  │
│  └──────────────────────────────────────────────────────────┘  │
│                        ↓                                        │
│  Step 2H: APPLY STATUS OVERRIDE                                │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ IF road.status = "blocked"  → Risk = 1.0 (maximum)      │  │
│  │ IF road.status = "partial"  → Risk = max(Risk, 0.75)    │  │
│  │ ELSE                         → Risk = min(Risk, 1.0)     │  │
│  └──────────────────────────────────────────────────────────┘  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

OUTPUT: Road Risk Score (0.0 to 1.0) for each segment
         ↓
         ↓


================================================================================
                  STEP 3: PREDICT DISRUPTIONS
================================================================================

FUNCTION: predict_disruptions(hours_ahead=24)
INPUT: Time horizon (default 24 hours)

PROCESS FLOW:
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│  For each Road in Database:                                    │
│                                                                 │
│  Step 3A: CALCULATE ROAD RISK (uses Step 2)                    │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ risk_score = calculate_road_risk(road)                   │  │
│  └──────────────────────────────────────────────────────────┘  │
│                        ↓                                        │
│  Step 3B: FETCH WEATHER DATA                                   │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ SELECT latest weather for district                       │  │
│  │ Extract: rainfall_mm, weather_condition                  │  │
│  └──────────────────────────────────────────────────────────┘  │
│                        ↓                                        │
│  Step 3C: TRIGGER PREDICTION CHECK                             │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ Predict = TRUE if ANY condition met:                     │  │
│  │                                                          │  │
│  │ 1. risk > 0.7                                           │  │
│  │ 2. road.status ∈ {blocked, partial}                     │  │
│  │ 3. (condition ∈ {poor, fair}) AND                       │  │
│  │    (terrain ∈ {hilly, mountainous})                     │  │
│  │ 4. rainfall >= 30mm                                     │  │
│  │                                                          │  │
│  │ IF NOT triggered → Skip to next road                    │  │
│  │ IF triggered     → Continue to Step 3D                  │  │
│  └──────────────────────────────────────────────────────────┘  │
│                        ↓                                        │
│  Step 3D: DETERMINE DISRUPTION TYPE                            │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ IF road.status = blocked                                │  │
│  │    → Type = "road_closure"                              │  │
│  │                                                          │  │
│  │ ELSE IF rainfall > 80mm                                 │  │
│  │    IF terrain ∈ {hilly, mountainous}                    │  │
│  │       → Type = "landslide"                              │  │
│  │    ELSE                                                 │  │
│  │       → Type = "flood"                                  │  │
│  │                                                          │  │
│  │ ELSE IF rainfall > 30mm                                 │  │
│  │    IF road.condition = poor                             │  │
│  │       → Type = "road_damage"                            │  │
│  │    ELSE                                                 │  │
│  │       → Type = "water_logging"                          │  │
│  │                                                          │  │
│  │ ELSE IF road.condition = poor                           │  │
│  │    → Type = "road_failure"                              │  │
│  │                                                          │  │
│  │ ELSE IF weather.condition = snow_rain                   │  │
│  │    → Type = "snow_blockage"                             │  │
│  │                                                          │  │
│  │ ELSE                                                    │  │
│  │    → Type = "traffic_congestion"                        │  │
│  └──────────────────────────────────────────────────────────┘  │
│                        ↓                                        │
│  Step 3E: ASSIGN CONFIDENCE LEVEL                              │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ IF risk > 0.85 OR road status = {blocked, partial}      │  │
│  │    → Confidence = "high"                                │  │
│  │                                                          │  │
│  │ ELSE IF risk > 0.70 OR                                  │  │
│  │         (condition ∈ {poor, fair} AND                   │  │
│  │          terrain ∈ {hilly, mountainous}) OR             │  │
│  │         rainfall >= 30mm                                │  │
│  │    → Confidence = "medium"                              │  │
│  │                                                          │  │
│  │ ELSE                                                    │  │
│  │    → Confidence = "low"                                 │  │
│  └──────────────────────────────────────────────────────────┘  │
│                        ↓                                        │
│  Step 3F: ESTIMATE DELAY                                       │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ Delay = 15 + (risk × 3 × 60 × (length / 50))            │  │
│  │ Delay = 15 + 3.6 × risk × length                        │  │
│  │                                                          │  │
│  │ Result: minutes of estimated delay                      │  │
│  └──────────────────────────────────────────────────────────┘  │
│                        ↓                                        │
│  Step 3G: CREATE PREDICTION RECORD                             │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ prediction = {                                           │  │
│  │   'road_id': road.id,                                    │  │
│  │   'road_name': road.name,                                │  │
│  │   'from': road.from_location,                            │  │
│  │   'to': road.to_location,                                │  │
│  │   'risk_score': risk,                                    │  │
│  │   'predicted_disruption': type,                          │  │
│  │   'confidence': confidence_level,                        │  │
│  │   'estimated_delay_minutes': delay,                      │  │
│  │   'recommended_action': action,                          │  │
│  │   'weather_data': weather_info,                          │  │
│  │   'coordinates': {from, to}                              │  │
│  │ }                                                        │  │
│  └──────────────────────────────────────────────────────────┘  │
│                                                                 │
│  OUTPUT: List of top 20 disruption predictions (sorted by risk)│
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

OUTPUT: Disruption predictions sorted by risk score (descending)
         ↓
         ↓


================================================================================
                   STEP 4: BUILD ROAD NETWORK GRAPH
================================================================================

FUNCTION: find_alternate_routes()
INPUT: from_location, to_location, shipment_type

PROCESS FLOW:
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│  Step 4A: FETCH ALL ROAD SEGMENTS                              │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ SELECT * FROM RoadSegment                                │  │
│  │ Load all available roads into memory                     │  │
│  └──────────────────────────────────────────────────────────┘  │
│                        ↓                                        │
│  Step 4B: GET SHIPMENT PRICING                                 │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ pricing = SHIPMENT_PRICING[shipment_type]                │  │
│  │                                                          │  │
│  │ Extract: min_price, max_price                            │  │
│  │ Calculate: base_cost = (min + max) / 2                  │  │
│  └──────────────────────────────────────────────────────────┘  │
│                        ↓                                        │
│  Step 4C: BUILD ADJACENCY GRAPH                                │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ graph = {}                                               │  │
│  │                                                          │  │
│  │ For each road:                                           │  │
│  │    1. Calculate risk = calculate_road_risk(road)         │  │
│  │    2. Set weight = length × (1 + risk × 2)              │  │
│  │       (higher risk = heavier weight)                     │  │
│  │    3. Add edge: from_location → to_location             │  │
│  │    4. Add reverse edge (bidirectional roads)             │  │
│  │                                                          │  │
│  │ graph[location] = [                                      │  │
│  │   {'to': next_location, 'weight': w, 'risk': r, ...}    │  │
│  │ ]                                                        │  │
│  └──────────────────────────────────────────────────────────┘  │
│                        ↓                                        │
│  Step 4D: NORMALIZE LOCATION NAMES                             │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ Create case-insensitive location mapping                 │  │
│  │ known_locations = {                                      │  │
│  │   'location'.lower(): 'location',                        │  │
│  │   ...                                                    │  │
│  │ }                                                        │  │
│  │                                                          │  │
│  │ source = known_locations[from_loc.lower()]              │  │
│  │ destination = known_locations[to_loc.lower()]            │  │
│  │                                                          │  │
│  │ IF source or destination not found:                      │  │
│  │    → Return fallback/air route                           │  │
│  └──────────────────────────────────────────────────────────┘  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

OUTPUT: Graph structure with weighted edges + source & destination
         ↓
         ↓


================================================================================
                    STEP 5: SEARCH ROUTE PATHS
================================================================================

FUNCTION: _search_route_paths(graph, source, destination)
INPUT: Graph, start location, end location

PROCESS FLOW:
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│  Algorithm: Dijkstra-inspired Shortest Path Search             │
│                                                                 │
│  Step 5A: INITIALIZE PRIORITY QUEUE                            │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ queue = [(cost=0, source_location, path=[], edges=[])]   │  │
│  │ routes = []                                              │  │
│  │ seen_paths = {}  (to avoid duplicate routes)             │  │
│  │                                                          │  │
│  │ sequence = 0  (tie-breaker for heap)                     │  │
│  └──────────────────────────────────────────────────────────┘  │
│                        ↓                                        │
│  Step 5B: MAIN LOOP - POP LOWEST COST PATH                     │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ WHILE queue not empty:                                   │  │
│  │                                                          │  │
│  │   1. Pop (cost, seq, current_location, path, edges)      │  │
│  │   2. new_path = path + [current_location]                │  │
│  │                                                          │  │
│  │   3. IF current_location = destination:                  │  │
│  │        ✓ Check if path already seen                      │  │
│  │        ✓ IF new: add to routes list                      │  │
│  │        ✓ CONTINUE (find more paths)                      │  │
│  │                                                          │  │
│  │   4. FOR each edge from current_location:                │  │
│  │        • IF edge.to in new_path: SKIP (avoid loops)      │  │
│  │        • IF edge.status = blocked AND avoid_blocked:     │  │
│  │          SKIP (respect road closures)                    │  │
│  │        • ELSE: Push to queue with new cost               │  │
│  │                                                          │  │
│  │ Output: Up to 5 distinct simple paths from source→dest   │  │
│  └──────────────────────────────────────────────────────────┘  │
│                        ↓                                        │
│  Step 5C: SORT ROUTES BY COST                                  │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ routes.sort(key = cost)                                  │  │
│  │                                                          │  │
│  │ Result: Cheapest (least risky) routes first              │  │
│  └──────────────────────────────────────────────────────────┘  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

OUTPUT: Up to 5 alternative routes (path + cost + edges)
         ↓
         ↓

================================================================================
                    STEP 7: RANK & SCORE ROUTES
================================================================================

FUNCTION: _rank_routes()
INPUT: Route details + shipment pricing

PROCESS FLOW:
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│  For each route:                                               │
│                                                                 │
│  Step 7A: CALCULATE COST METRICS                               │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ cost_rate = base_cost_per_km                             │  │
│  │             × (3.5 if air_route else 1.0)                │  │
│  │                                                          │  │
│  │ estimated_cost = distance × cost_rate                    │  │
│  │ cost_per_km = estimated_cost / distance                  │  │
│  │                                                          │  │
│  │ cost_efficiency = min(100,                               │  │
│  │                   (50 × base_cost) / cost_per_km)        │  │
│  └──────────────────────────────────────────────────────────┘  │
│                        ↓                                        │
│  Step 7B: CALCULATE SAFETY SCORE (0-40 points)                │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ IF route.blocked = TRUE:                                 │  │
│  │    safety_score = 0                                      │  │
│  │                                                          │  │
│  │ ELSE:                                                    │  │
│  │    safety_score = (1 - average_risk) × 40                │  │
│  │                                                          │  │
│  │ Range: [0, 40]                                           │  │
│  └──────────────────────────────────────────────────────────┘  │
│                        ↓                                        │
│  Step 7C: CALCULATE COST SCORE (0-40 points)                  │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ IF route.blocked = TRUE:                                 │  │
│  │    cost_score = 0                                        │  │
│  │                                                          │  │
│  │ ELSE:                                                    │  │
│  │    cost_score = cost_efficiency × 0.4                    │  │
│  │                                                          │  │
│  │ Range: [0, 40]                                           │  │
│  └──────────────────────────────────────────────────────────┘  │
│                        ↓                                        │
│  Step 7D: CALCULATE SPEED SCORE (0-20 points)                 │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ fastest_time = min(estimated_time across all routes)     │  │
│  │                                                          │  │
│  │ IF route.blocked = TRUE:                                 │  │
│  │    speed_score = 0                                       │  │
│  │                                                          │  │
│  │ ELSE:                                                    │  │
│  │    speed_score = min(20,                                 │  │
│  │        (fastest_time / estimated_time) × 20)             │  │
│  │                                                          │  │
│  │ Range: [0, 20]                                           │  │
│  └──────────────────────────────────────────────────────────┘  │
│                        ↓                                        │
│  Step 7E: CALCULATE TOTAL ROUTE SCORE                          │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ route_score = safety_score + cost_score + speed_score    │  │
│  │                                                          │  │
│  │ Range: [0, 100]                                          │  │
│  │                                                          │  │
│  │ Higher score = Better route                              │  │
│  └──────────────────────────────────────────────────────────┘  │
│                        ↓                                        │
│  Step 7F: GENERATE RECOMMENDATIONS                             │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ IF average_risk > 0.9:                                   │  │
│  │    action = "ROUTE CLOSURE RECOMMENDED"                  │  │
│  │                                                          │  │
│  │ ELSE IF average_risk > 0.8:                              │  │
│  │    action = "HEAVY RESTRICTION"                          │  │
│  │                                                          │  │
│  │ ELSE IF average_risk > 0.7:                              │  │
│  │    action = "CAUTION REQUIRED"                           │  │
│  │                                                          │  │
│  │ ELSE:                                                    │  │
│  │    action = "NORMAL PRECAUTIONS"                         │  │
│  └──────────────────────────────────────────────────────────┘  │
│                        ↓                                        │
│  Step 7G: SORT ROUTES BY COMPOSITE SCORE                       │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ Sort by:                                                 │  │
│  │    1. route_score (descending) - highest score first      │  │
│  │    2. safety_score (descending) - if tied                │  │
│  │    3. -estimated_time (ascending) - if still tied        │  │
│  │                                                          │  │
│  │ Result: Ranked list from BEST to WORST                   │  │
│  └──────────────────────────────────────────────────────────┘  │
│                        ↓                                        │
│  Step 7H: ADD FALLBACK ROUTES                                  │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ IF all routes are blocked:                               │  │
│  │    • Calculate direct distance via Haversine formula      │  │
│  │    • Create air corridor as last resort                  │  │
│  │    • Multiply cost by 3.5 (air multiplier)               │  │
│  └──────────────────────────────────────────────────────────┘  │
│                                                                 │
│  FINAL OUTPUT:                                                 │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ Routes Array (sorted by quality):                        │  │
│  │ [                                                        │  │
│  │   {                                                      │  │
│  │     'from': location1,                                   │  │
│  │     'to': location2,                                     │  │
│  │     'route_score': 85.5,  ← MAIN SCORE                   │  │
│  │     'safety_score': 32.0,                                │  │
│  │     'cost_score': 35.0,                                  │  │
│  │     'speed_score': 18.5,                                 │  │
│  │     'total_distance_km': 250,                            │  │
│  │     'estimated_time_minutes': 360,                       │  │
│  │     'estimated_cost_inr': 12500,                         │  │
│  │     'average_risk': 0.42,                                │  │
│  │     'segments': [...],                                   │  │
│  │     'recommended_action': "CAUTION REQUIRED"             │  │
│  │   },                                                     │  │
│  │   ...                                                    │  │
│  │ ]                                                        │  │
│  └──────────────────────────────────────────────────────────┘  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

OUTPUT: Ranked list of routes with scores sent to user/API

================================================================================
                    STEP 4: GRAPH BUILDING - DATA SOURCES
================================================================================

All Road Segments
  ├─ Source: RoadSegment table
  ├─ SQL: SELECT * FROM RoadSegment
  ├─ ORM: RoadSegment.query.all()
  ├─ Data Age: Static (loaded once per request)
  ├─ Columns Used: id, from_location, to_location, length_km,
  │              from_lat, from_lng, to_lat, to_lng, status
  └─ How Used: Build adjacency list graph


Edge Weights Calculation
  ├─ Components:
  │    • road.length_km (from RoadSegment)
  │    • risk_score (from Step 2 calculation)
  ├─ Formula: weight = length × (1 + risk × 2)
  ├─ Logic: Higher risk = heavier weight (longer virtual distance)
  ├─ Example: 100km road with 0.5 risk
  │    weight = 100 × (1 + 0.5 × 2) = 100 × 2 = 200
  └─ How Used: Dijkstra algorithm for pathfinding


Location Names Matching
  ├─ Source: User input + RoadSegment from/to_location columns
  ├─ API: /api/routes?from=Imphal&to=Aizawl
  ├─ Lookup Method: Case-insensitive matching
  ├─ Data Structure: Dictionary mapping
  │    known_locations = {
  │      'imphal': 'Imphal',
  │      'aizawl': 'Aizawl',
  │      ...
  │    }
  ├─ Fallback: If location not found → return empty/fallback route
  └─ How Used: Map user input to actual road endpoints


User Parameters
  ├─ from_location: String (start point)
  ├─ to_location: String (destination)
  ├─ shipment_type: {small_pickup, light_commercial, medium_heavy, large_container}
  ├─ avoid_high_risk: Boolean (True = skip risky roads)
  ├─ Data Entry: Web form or mobile app API request
  └─ How Used: Filter graph edges & calculate pricing

Graph Structure (In-Memory)

  ├─ Source: RoadSegment + Step 2 calculations
  ├─ Fields:
  │    'to': destination location
  │    'weight': Dijkstra cost
  │    'risk': risk score [0-1]
  │    'status': {open, partial, blocked}
  │    'road_key': unique identifier
  │    'road': RoadSegment object reference
  └─ How Used: Decision-making in pathfinding


Blocking Rules
  ├─ Rule 1: IF edge.status = 'blocked' AND avoid_blocked = True
  │          → Skip this edge (don't traverse)
  ├─ Rule 2: IF node in new_path → Skip (avoid loops)
  ├─ Rule 3: IF queue size > 5 routes found → Stop searching
  └─ How Used: Generate alternative safe routes

  ├─ Source: RoadSegment properties (from edges)
  ├─ Data: length_km, condition, status, coordinates
  ├─ Accessed Via: Direct property access from road object
  ├─ Columns: from_lat, from_lng, to_lat, to_lng
  ├─ Aggregation: Sum all segment lengths, conditions
  └─ How Used: Build detailed route object


Coordinates
  ├─ Source: RoadSegment lat/lng columns
  ├─ Format: Decimal degrees (e.g., 24.8245, 93.9456)
  ├─ Columns: from_lat, from_lng, to_lat, to_lng
  ├─ Precision: ~100 meters per decimal place
  ├─ Data Age: Static (from import)
  └─ How Used: Display on map via Google Maps API


Travel Time Estimation
  ├─ Method: Distance / average_speed
  ├─ Average Speed: 40-60 km/hour (hardcoded assumption)
  ├─ Calculation: (distance_km / 50) × 60 minutes
  ├─ Source: Hardcoded in code (not from database)
  ├─ Data Age: Constant (same for all routes)
  └─ How Used: Speed score calculation


Segment Metadata
  ├─ Source: RoadSegment table
  ├─ Fields: name, road_type, terrain, condition, status
  ├─ Used For: Display in segments list
  └─ How Used: User-friendly route description


================================================================================
                    STEP 7: SCORING & RANKING - DATA SOURCES
================================================================================

Cost Information
  ├─ Base Cost: SHIPMENT_PRICING[selected_vehicle_type]
  ├─ Source: Constants (ai_engine.py)
  ├─ Lookup: 'medium_heavy' → {'min': 40, 'max': 65}
  ├─ Calculation: base_cost = (min + max) / 2 = 52.5
  ├─ Distance: From route total_distance_km
  ├─ Air Multiplier: 3.5× if air_route detected
  ├─ Formula: total_cost = distance × base_cost × multiplier
  └─ How Used: Calculate cost_per_km and cost_score


Risk Scores
  ├─ Source: Aggregated from all route segments (Step 2)
  ├─ Calculation: average_risk = Σ(segment_risk) / num_segments
  ├─ Range: [0, 1]
  ├─ Data Age: Freshly calculated per request
  ├─ Stored In: route['average_risk']
  └─ How Used: Calculate safety_score = (1 - avg_risk) × 40


Time Data
  ├─ Source: Calculated in Step 6
  ├─ Field: estimated_time_minutes
  ├─ Reference: min(time) across all routes
  ├─ Calculation: (distance / avg_speed) × 60
  ├─ Data Age: Freshly calculated
  └─ How Used: Calculate speed_score = (fastest_time / route_time) × 20


Recommendation Rules
  ├─ Source: Hardcoded decision tree (ai_engine.py)
  ├─ Method: _recommend_action(risk, disruption_type)
  ├─ Thresholds:
  │    risk > 0.9 → "ROUTE CLOSURE RECOMMENDED"
  │    risk > 0.8 → "HEAVY RESTRICTION"
  │    risk > 0.7 → "CAUTION REQUIRED"
  │    risk ≤ 0.7 → "NORMAL PRECAUTIONS"
  ├─ Data Age: Constant (rule-based)
  └─ How Used: Generate actionable recommendation


Ranking Sort Order
  ├─ Primary: Sort by route_score (descending)
  ├─ Secondary: Sort by safety_score (descending if tied)
  ├─ Tertiary: Sort by -estimated_time (ascending if still tied)
  ├─ Algorithm: Python sorted() with custom comparator
  ├─ Output: Best routes first
  └─ How Used: Present routes in priority order

The 7-step process creates a complete intelligent routing system:

1. INITIALIZE      → Set up scoring parameters
2. CALCULATE       → Measure road safety using multiple factors
3. PREDICT         → Identify dangerous situations ahead
4. BUILD NETWORK   → Create road connectivity graph
5. PATHFIND        → Discover alternative routes
6. AGGREGATE       → Compile detailed route information
7. SCORE & RANK    → Evaluate and present best options

Each step builds on the previous one, transforming raw data into
actionable route recommendations with safety, cost, and time analysis.
